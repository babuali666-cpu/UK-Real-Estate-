# UK Real Estate Website

A professional real estate website designed for showcasing and listing properties across the United Kingdom.

## Features

✨ **Modern & Responsive Design**
- Fully responsive layout that works on all devices (desktop, tablet, mobile)
- Clean and professional UI/UX
- Smooth animations and transitions

🏠 **Property Listings**
- Featured properties section with beautiful cards
- Property details including bedrooms, bathrooms, and square footage
- Price display with property location
- High-quality property images with hover effects

🔍 **Search Functionality**
- Advanced property search by location/postcode
- Filter by property type (House, Flat, Bungalow, Commercial)
- Easy-to-use search interface

📱 **Navigation**
- Sticky navigation bar
- Smooth scrolling between sections
- Mobile-friendly menu

ℹ️ **About Section**
- Company information and mission
- Key features and statistics
- 5000+ properties sold
- 10,000+ happy clients
- 50+ UK locations

📧 **Contact Section**
- Contact form for inquiries
- Phone number
- Email address
- Physical address
- Social media links

## Getting Started

1. Clone or download the repository
2. Open `index.html` in your web browser
3. The website is fully functional without requiring a backend server

## Features in Detail

### Navigation
- Quick links to all major sections
- Active state indicator for current section
- Sticky navigation for easy access

### Hero Section
- Eye-catching banner with call-to-action
- Search box for finding properties
- Professional gradient background

### Properties Grid
- Responsive grid layout (1-4 columns based on screen size)
- Property cards with hover effects
- Price tags
- Property specifications (beds, baths, size)
- "View Details" buttons

### Responsive Breakpoints
- Desktop: Full layout
- Tablet (768px): Adjusted grid and spacing
- Mobile (480px): Single column layout
